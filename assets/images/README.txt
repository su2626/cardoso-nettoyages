RÉPERTOIRE IMAGES — CARDOSO NETTOYAGES SÀRL
============================================

Ce dossier accueille les images définitives du site. En attendant,
le site utilise des images Unsplash haute qualité chargées via URL
dans le CSS et le HTML.

Images suggérées à fournir pour remplacer les placeholders :

1. hero.jpg
   - Usage : fond du hero (section #accueil)
   - Format : 2000x1200px minimum, JPG optimisé
   - Sujet : nuancier de propreté professionnelle, sols brillants,
            bureaux modernes éclairés. Plan large, ambiance soignée.

2. about.jpg
   - Usage : visuel section "À propos"
   - Format : 1200x1500px (ratio 4:5), JPG optimisé
   - Sujet : équipe en action, matériel professionnel, geste précis.

3. services-bg.jpg
   - Usage : fond parallax de la section "Services"
   - Format : 2000x1500px, JPG optimisé (utilisé en filigrane à 12%)
   - Sujet : immeuble, vitres, façade urbaine moderne.

4. logo.svg (optionnel)
   - Usage : peut remplacer le logo généré en CSS dans la navbar.
   - Format : SVG vectoriel, monochrome ou bichromie rouge/blanc.

Conseils d'optimisation :
   - Compression : utiliser TinyPNG, Squoosh ou ImageOptim
   - Format moderne : proposer un fallback WebP/AVIF si possible
   - Lazy loading déjà géré côté CSS via parallax & opacity
